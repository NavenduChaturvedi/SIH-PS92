# Financial Assistance Platform

An intelligent platform that helps users discover and assess suitable financial assistance schemes through **natural language, voice, and multilingual input**.

> **Smart India Hackathon 2026 · Problem Statement 26092**

## ✨ Features

* 📝 Natural-language financial assistance requests
* 🎙️ Voice-based applications
* 🌐 Multilingual support
* 🧮 Eligibility & loan simulation
* 📍 Location-based partner matching
* 💰 EMI estimation

## 🛠️ Tech Stack

**Frontend:** Vue 3, Vite, Tailwind CSS
**Backend:** Python, FastAPI, SQLAlchemy
**Database:** PostgreSQL, PostGIS
**APIs:** Translation & Speech Recognition

## 🚀 Setup

### Backend

```bash
cd backend
python -m venv venv
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
